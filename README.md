# 세브렌 AI 버그 제보소

세브렌 AI를 쓰시다가 발견한 **버그**나 **개선 아이디어**를 이곳에서 받고 있습니다.
남겨주신 내용은 운영자가 직접 확인하고 답변드립니다. 편하게 남겨주세요!

---

## 제보하는 방법

1. 이 페이지 위쪽의 **Issues** 탭을 클릭합니다.
2. 초록색 **New issue** 버튼을 누릅니다.
3. 제목과 내용을 작성하고 **Create** 버튼을 누르면 끝입니다.

> 💡 GitHub 계정이 필요합니다. 없으시면 [무료 가입](https://github.com/signup) 후 이용해주세요.
> 제보 후 답변이 달리면 가입하신 이메일로 알림이 갑니다.

---

## 이렇게 적어주시면 큰 도움이 됩니다

제목은 한 줄 요약으로 적어주세요. 예: `음성 입력 후 저장 버튼이 눌리지 않음`

내용에는 아래 항목을 채워주시면 가장 빠르게 해결할 수 있어요. 복사해서 쓰세요.

```
## 무슨 일이 있었나요?
(어떤 문제가 발생했는지 편하게 적어주세요)

## 어떻게 하면 다시 재현되나요?
1.
2.
3.

## 기대했던 결과
(원래는 어떻게 동작해야 한다고 생각하셨나요?)

## 실제 결과
(실제로는 어떻게 동작했나요?)

## 사용 환경
- 기기: (예: iPhone 15 / 갤럭시 S24 / 윈도우 노트북)
- 브라우저 또는 앱 버전: (예: Chrome 최신 / 앱 1.0.2)

## 스크린샷 또는 영상
(있으면 이미지 파일을 그대로 드래그해서 붙여넣으시면 업로드됩니다)
```

전부 채우지 않으셔도 괜찮습니다. **"무슨 일이 있었나요"와 "재현 방법"만 있어도 충분히 도움이 됩니다.**

## 자주 묻는 질문

**Q. 버그가 아니라 그냥 기능 제안인데 여기 써도 되나요?**
네, 환영합니다. 제목 앞에 `[제안]` 을 붙여주시면 구분하기 좋습니다.

**Q. 이미 누가 올린 내용인지 어떻게 확인하나요?**
Issues 탭에서 검색해보시고, 같은 내용이 있으면 새로 만드는 대신 댓글이나 👍 반응을 남겨주세요.

**Q. 제가 쓴 제보는 다른 사람도 볼 수 있나요?**
네, 이 저장소는 공개(Public)라 누구나 볼 수 있습니다. 개인정보나 계정 비밀번호, 로그인 정보 등 **민감한 내용은 절대 적지 말아주세요.**

**Q. 보안 취약점을 발견했는데요?**
공개 이슈로 올리지 마시고 운영자에게 개별적으로 연락해주세요.

---

## 처리 흐름

제보해주신 이슈는 다음과 같이 관리됩니다.

| 상태 | 의미 |
|---|---|
| Open | 접수됨 / 확인 중 |
| Closed | 수정 완료 또는 처리 종료 |

수정이 완료되면 해당 이슈에 댓글로 알려드린 뒤 닫습니다.
