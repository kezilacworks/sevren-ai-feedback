# 세브렌 AI 버그 제보소

세브렌 AI를 쓰시다가 발견한 **버그**나 **개선 아이디어**를 이곳에서 받고 있습니다.
남겨주신 내용은 운영자가 직접 확인하고 답변드립니다. 편하게 남겨주세요!

## 제보하는 방법

**[👉 여기를 눌러 바로 제보하기](../../issues/new/choose)**

1. 위 링크(또는 이 페이지 위쪽 **Issues** 탭 → **New issue**)를 누릅니다.
2. 제보 종류를 고릅니다. 버그 / 기능 제안 / 기타 문의 중에 선택하시면 됩니다.
3. 화면에 뜨는 **양식의 빈칸을 채우고** 아래 **Create** 버튼을 누르면 끝입니다.

작성 양식은 자동으로 나타나니 따로 준비하실 건 없습니다.
별표가 없는 항목은 비워두셔도 제출됩니다.

> 💡 GitHub 계정이 필요합니다. 없으시면 [무료 가입](https://github.com/signup) 후 이용해주세요.
> 제보 후 답변이 달리면 가입하신 이메일로 알림이 갑니다.

## 제보 종류

| 종류 | 이럴 때 쓰세요 |
|---|---|
| 🐞 버그 제보 | 오류가 나거나, 눌러도 반응이 없거나, 결과가 이상할 때 |
| 💡 기능 제안 | 이런 기능이 있으면 좋겠다는 아이디어가 있을 때 |
| 💬 기타 문의 | 사용법 질문이나 그 밖의 이야기 |

## 자주 묻는 질문

**Q. 스크린샷은 어떻게 첨부하나요?**
양식의 텍스트 입력칸에 이미지 파일을 그대로 끌어다 놓으면 자동으로 업로드됩니다.

**Q. 이미 누가 올린 내용인지 어떻게 확인하나요?**
[Issues 탭](../../issues)에서 검색해보시고, 같은 내용이 있으면 새로 만드는 대신 댓글이나 👍 반응을 남겨주세요.

**Q. 제가 쓴 제보는 다른 사람도 볼 수 있나요?**
네, 이 저장소는 공개(Public)라 누구나 볼 수 있습니다. 개인정보나 계정 비밀번호, 로그인 정보 등 **민감한 내용은 적지 말아주세요.**

**Q. 보안 취약점을 발견했는데요?**
공개 이슈로 올리지 마시고 운영자에게 개별적으로 연락해주세요.

## 처리 흐름

| 상태 | 의미 |
|---|---|
| Open | 접수됨 / 확인 중 |
| Closed | 수정 완료 또는 처리 종료 |

수정이 완료되면 해당 이슈에 댓글로 알려드린 뒤 닫습니다.

시간 내어 제보해주셔서 감사합니다. 덕분에 세브렌 AI가 더 좋아집니다 🙏
